# 真实合规词库（本目录 *.txt 已被 gitignore，永不进仓库）

auth-server 启动时会从本目录读取真实红/黄线词，经 `/compliance/dict` 以 gzip+base64 下发到客户端的
`backend/dict/*.local.txt`（同样 gitignore），客户端运行时优先加载。**真实敏感词只存在于你本机/你的服务器，永不进 git。**

## 放词方法

在本目录新建两个文件（不存在时自动回落到占位词）：

- `red.txt` —— 红线词（命中即硬拦截，累计 3 次封号）
- `yellow.txt` —— 黄线词（命中只提醒，不拦截）

每行一条，格式 `词|分类`（分类可省略），`#` 开头为注释。例如：

```
# 这是注释
某词|分类A
另一个词|分类B
仅词不带分类
```

改完**重启 auth-server** 即生效（词库版本号按内容哈希自动变化，客户端会自动重新同步）。

## 注意
- 不要把真实词写进 `app/main.py` 或任何被 git 跟踪的文件。
- 客户端 `backend/dict/red.txt`、`yellow.txt` 只放占位演示词，真实词一律走本目录云端下发。
