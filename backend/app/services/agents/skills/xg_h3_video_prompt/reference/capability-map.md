# MiniMax H3 能力路由

核心原则：**先判用户真正要控制什么，再选能力路径**。以一个主能力承载任务，辅能力按需叠加；不按题材检索模板。

---

## 一、商用内容生成方向

题材只决定强调项，不决定固定模板。用户的具体目标永远优先于下表的常见写法。

### 品牌大片与影视内容
- **信号词**：品牌片、TVC、预告片、电影感、时尚大片
- **提示词要点**：核心概念 → 主体关系 → 镜头节奏 → 品牌资产 → 整体视听调性 → 落幅
- **西瓜短剧适配**：适用于片头/转场/高潮段落的电影感强化

### 视觉创意与内容包装
- **信号词**：动态海报、片头、文字特效、实拍融合、视觉实验
- **提示词要点**：视觉媒介 → 版式层级 → 遮罩/转场触发 → 文字白名单 → 卡点/音效反馈

### AI 剧情内容创作（短剧核心）
- **信号词**：短剧、对话、关系冲突、角色表演、情节钩子
- **提示词要点**：
  - 角色身份 + 关系
  - 情绪递进（不能一开始就爆发）
  - 动作与视线方向（谁看谁、谁回避）
  - 对白节奏
  - 正反打或连续调度
  - 结尾钩子（让观众想看下一镜）
- **西瓜特化**：3–5 秒单镜，单情绪推进，台词 4 字/秒 + 停顿

### 产品与电商营销
- **信号词**：产品广告、功能演示、开箱、服饰展示、带货
- **提示词要点**：产品结构锁定 → 功能顺序 → 功能演示 → 材质特写 → 使用场景 → Hero Shot + 品牌文字

### 数字体验与游戏创意
- **信号词**：UI/UX、网页动效、游戏界面、第一人称、交互演示
- **提示词要点**：交互顺序 → 第一/三人称逻辑 → UI 画面锁定 → 文字/数字 → 操作反馈与状态变化

### 硬件、实体工业、具身智能
- **信号词**：机械、机器人、制造流程、工业演示、空间操作
- **提示词要点**：几何结构 → 部件数量 → 关节与运动范围 → 操作顺序 → 接触与力 → 环境反馈 → 安全边界 → 完成态

### 动画与风格化影像
- **信号词**：2D 动画、3D 卡通、定格、剪纸、像素、国风、风格实验
- **提示词要点**：单一视觉系统 → 线稿/材质/帧感/运动规律 → 角色一致性 → **禁止媒材混搭**

## 二、原生多模态理解与生成

### 多素材联合参考
- 先建素材职责表，再写优先级和冲突裁决
- 提示词必须回答：每个素材负责什么 / 什么必须保持 / 什么可以变化

### 角色、动作与镜头参考分离
- 角色图 → 身份/面部/发型/体型/服装
- 产品图 → 结构/标签/材质/品牌
- 动作视频 → 运镜/机位/运动/构图/剪辑/节奏
- 风格图 → 仅控光色/媒材，不控角色身份
- 用户说"保留原视频的拍摄方式"时 → 逐层锁定动作、机位、运镜、转场、卡点，**不是一句"参考视频1"就完事**

### 音色克隆与迁移
- 先明确音频主控：音色 / 台词 / 音乐 / 节拍
- 音色迁移需声明：说话人、精确台词、情绪、时机、口型同步、保留/删除哪些原音层

## 三、全能精准编辑与修改

### 角色与物体编辑
- 声明编辑对象的最终态
- 未提及的人物、物体、动作、遮挡、光照、镜头保持不变
- 替换物体要适应原有的握持/接触/运动模糊/反射/阴影

### 场景与视觉效果编辑
- 修改背景/时间/天气/光照/风格时 → 同步调整主体光照、环境反射、阴影、景深、遮挡
- 局部风格化必须定义范围，避免错误重绘整个画面

### 声音、台词与音色修改
- 声明哪些音层保留、替换、删除
- 修改台词 → 同时修改口型、停顿、气息、表情、动作强度
- 修改音色 → 保持说话人身份与空间声学合理

### 高精度指令遵循
- 多项编辑拆成**原子清单**：每条 = 对象 + 位置 + 原始态约束 + 最终态
- 校验：是否漏编 / 是否误改未提及内容 / 编辑间是否冲突 / 是否影响光遮挡声音接触 / 文字颜色数量左右顺序是否准确
- 单点编辑用短指令，多点编辑用明确列表
- **不要**把精准编辑扩展为新故事创作

---

## 四、路由规则（判定顺序）

按以下顺序判定，命中即停：

1. 用户要**修改已有视频**？→ 精准编辑
2. 用户要**保留参考视频的动作/镜头/节奏**？→ 多模态参考 + 逐层锁定策略
3. 用户需要**精确的角色/产品/风格/声音**？→ 把职责分配到对应素材
4. 用户提供**首帧/尾帧图**且要求固定起幅/落幅？→ 首尾帧模式
5. 否则 → 文生视频 + 商用内容方向组织镜头

同类能力可叠加，但保持一个清晰的主任务。
