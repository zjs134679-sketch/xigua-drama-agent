# H3 提示词框架：六层控制模型

把提示词当作**六个控制层**来组织，而非美学描述。

## 六层结构

| 层级 | 控制内容 | 关键问题 |
|------|---------|---------|
| 1. 目的层 | 成片要达成什么 | 观众看完应该感受到什么 |
| 2. 不变量层 | 什么绝对不能变 | 人物/产品/场景的哪些视觉特质必须锁定 |
| 3. 事件层 | 发生了什么 | 时间轴上推进了哪些动作/状态变化 |
| 4. 摄影层 | 怎么拍的 | 景别/机位/运动/转场 |
| 5. 质感层 | 画面什么质感 | 光色/媒材/帧感/后期 |
| 6. 声音层 | 听到什么 | 对白/音乐/环境/动作音效 |

> **原则**：先解决不变量、事件和摄影，再补质感。不要一上来就堆风格形容词。

---

## 信息密度与时间轴

### 单镜头连续推进
```
开场构图 → 主体动作 → 镜头反应 → 状态变化 → 落幅构图
```

### 多镜头分段
每段一个主视觉任务：
- 0-N秒（钩子）：抓住注意力
- N-M秒（展示）：呈现核心内容
- M-K秒（落幅）：收束，留记忆点

### 短剧 3–5 秒单镜特化
短剧单镜 ≤ 5 秒，用**一个连续动作链**覆盖：
```
0-1s：起幅构图 + 人物状态
1-3s：核心动作/表情变化/反应
3-5s：落幅结果 + 情绪收束
```

---

## 素材职责绑定

- **一个素材一个主职责**（可附带一个次要职责）
- 声明素材冲突时的裁决规则
- 尽量减少上传量：近似重复素材导致身份漂移和风格混合

---

## 一致性与编辑

### 锁定身份/产品
用可观测的视觉锚点描述，不用抽象形容词：
- ✅ "鼻梁高挺、左侧眉尾有颗小痣、下颌线棱角分明"
- ❌ "长得好看、气质优雅"

### 精准编辑：最小差异指令
```
严格复现视频1的时长、镜头、动作、构图、节奏和声音，只做以下变化：
1. 角色服装从红色改为深蓝色
2. 背景从室内改为晴天室外
3. 保持所有其他元素不变
```

### 视觉换皮
结构锁定 + 视觉重做：
- 保持：时长、镜头序列、动作时间点、构图、剪辑点、声音
- 重做：光色、材质、渲染风格

---

## 镜头与转场

- 镜头术语**锚定到主体行为**：跟随冷凝水珠滑落 → 对焦瓶身标签（而非泛写"产品特写"）
- 转场需要**触发条件 + 剪切时刻**，不是写"平滑过渡"就完事

---

## 文字与声音

### 文字白名单
- 列出允许出现的所有文字及数量
- 默认无文字（除非明确要求）

### 声音层级
```
对白：谁说的、说什么、情绪、时机
音乐：类型、节拍、情绪弧线
环境：空间特征（室内/室外/大小/材质）
动作音效：与画面动作的同步点
```

---

## 题材适配

不要强制套用所有字段。不同题材决定不同强调项：
- 短剧 → 角色身份、关系、情绪递进、结尾钩子
- 产品 → 几何结构、材质、功能顺序、Hero Shot
- 动画 → 单一视觉系统、线稿/材质/运动规律
- 工业 → 部件数量、关节范围、操作顺序、安全边界

---

## 常见失败模式

1. **当作案例库检索**：每次需求不同，模板拼凑必然出错
2. **素材职责未声明**：多素材时模型不知道谁管什么
3. **风格形容词堆砌**：一上来就写"电影感、高级感、赛博朋克"，但没有不变量和事件
4. **动作过载**：5 秒里塞 3 个转身 + 2 个表情变化 + 1 个运镜
5. **约束冲突**：同时要求"固定角色"和"自由发挥风格"
6. **重复锁定**：同一特征在不同位置多次描述，互相矛盾
7. **文字失控**：不声明白名单，模型自行加字
8. **编辑变重拍**：精准编辑提示词被扩展为新故事
9. **占位语残留**："可自行补充""根据实际情况调整"等无效内容
