# MiniMax H3 官方参数边界

> 基于公开文档，最后更新 2026-08-01。如有变化以 MiniMax 官方文档为准。

## 支持模式

- 文生视频（text-to-video）
- 首帧/尾帧/首尾帧图生视频（first-last-frame，0–2 张图）
- 多模态参考生成（multimodal reference，图片/视频/音频任意合法组合）
- 视频编辑（video editing，多模态参考的一种应用形态）

## 输出参数

| 参数 | 限制 |
|------|------|
| 模型 | MiniMax-H3 |
| 分辨率 | 2K |
| 时长 | 4–15 秒（仅整数） |
| 画幅 | 16:9 / 9:16 / 1:1 / 4:3 / 3:4 / 3:2 / 2:3 / 21:9 |
| 提示词上限 | 7000 字符（UTF-8 计字符数） |

> ⚠️ 文生视频不支持 `adaptive` 画幅，必须明确指定。

## 首尾帧输入

| 参数 | 限制 |
|------|------|
| 数量 | 0–2 张 |
| 像素范围 | 256–5760 px |
| 画幅比 | 2:5–5:2 |
| 格式 | JPG / JPEG / PNG / WEBP / HEIC / HEIF |

## 多模态参考输入

| 素材类型 | 数量上限 | 单文件时长 | 总时长 | 单文件大小 | 格式 |
|----------|----------|-----------|--------|-----------|------|
| 图片 | 9 张 | — | — | ≤ 30 MB | 同首尾帧 |
| 视频 | 3 段 | 2–15 秒 | ≤ 15 秒 | ≤ 50 MB | H.264/H.265, AAC/MP3 |
| 音频 | 3 段 | 2–15 秒 | ≤ 15 秒 | ≤ 15 MB | WAV / MP3 |

- **总文件数 ≤ 12**
- **音频不可单独使用**（必须搭配图片或视频）
- 请求体 ≤ 64 MB（大文件优先用 URL）

## 素材职责边界

| 素材类型 | 主控维度 | 不控维度 |
|----------|---------|---------|
| 图片（角色） | 身份、面部、发型、体型、服装 | 动作、镜头运动 |
| 图片（产品） | 结构、标签、材质、品牌 | 环境、光照 |
| 图片（风格） | 光色、媒材、质感 | 角色身份 |
| 视频 | 动作、运镜、构图、剪辑、节奏 | 角色外观（除另有声明） |
| 音频 | 音色、台词、节拍、音乐 | 画面内容 |

## 常见被拒原因

1. 提示词超过 7000 字符
2. 时长非整数或超出 4–15 秒
3. 文生视频使用了 adaptive 画幅
4. 多素材时未明确职责分配
5. 音频单独使用（无图片/视频搭配）
6. 视频总时长超过 15 秒
7. 文件总数超过 12
