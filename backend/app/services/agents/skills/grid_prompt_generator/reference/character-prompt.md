# 西瓜短剧角色图片提示词模板

## 模板结构

```
西瓜短剧写实人物设定图，真人选角参考照，角色四视图/全身参考图。
身份：[性别]，[年龄]，[身材]，[气质]，[角色定位]。
脸部设计：[脸型]，[眼睛]，[鼻子和嘴]，[肤色]，[皮肤质感]，[表情]。
发型设计：[发色]，[发长]，[发型]，[发际线/刘海/胡须等特征]。
服装设计：[完整穿搭]，[布料材质]，[颜色]，[领口/袖子/腰部/鞋子]，[符合时代背景]。
姿态版式：中性站姿，浅灰干净影棚背景，同一张脸、同一发型、同一身材、同一套衣服，不要文字标签，不要额外人物。
风格：电影感真实摄影，高细节，清晰对焦，统一短剧画风。
```

## 示例

```
西瓜短剧写实人物设定图，真人选角参考照，年轻女性全身正面参考图。
身份：二十岁出头女性，身材修长，气质冷静自信，都市设计师。
脸部设计：精致鹅蛋脸，明亮杏眼，自然鼻子和嘴，暖调自然肤色，轻微真实皮肤纹理，表情从容。
发型设计：黑色长发，发尾微卷，自然垂在肩侧，轮廓清晰。
服装设计：复古蓝色旗袍，细致花纹刺绣，贴合领口和袖口，布料褶皱清楚，搭配简洁鞋子。
姿态版式：中性站姿，浅灰干净影棚背景，同一张脸、同一发型、同一身材、同一套衣服，不要文字标签，不要额外人物。
风格：电影感真实摄影，高细节，清晰对焦，统一短剧画风。
```

## 关键规则

- 人物资产用于后续分镜一致性，必须优先保证“同一张脸、同一发型、同一身材、同一套衣服”。
- 角色图默认适合做参考图，不要生成复杂剧情环境、多人场景或夸张动作。
- 如果角色属于古代/年代剧，服装必须写清时代材质和结构，避免现代制服、拉链、口袋、徽章等错误元素。
