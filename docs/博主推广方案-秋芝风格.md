## 一、产品定位（给博主的「电梯稿」）

### 1.1 我们是谁

**西瓜短剧 Agent** = 桌面端 AI 短剧工厂：

```
小说/剧本 → 事件图谱 → 分集改编 → 抽角色/场景/道具
→ 分镜拆解 → 审查 → 出图 → 图生视频 → 时间线 → 导出 MP4
```

| 差异点 | 观众听得懂的说法 |
|--------|------------------|
| 全链路，不是单点工具 | 不是「只会出图」或「只会写剧本」，是一条产线 |
| 国内合规 | 红线硬拦、黄线提示，面向能播的内容 |
| 画风/类型/节奏技能包 | 选都市/仙侠/悬疑 + 画风 + 节奏，不是从零写提示词 |
| 本地 Comfy + 国内算力 | 可本地、可接节点，适合想控成本/数据的团队 |
| 流水线进度条 | 顶栏告诉你「下一步缺什么」——小白不会迷路 |
| 桌面软件 | 双击启动，工作台深色专业 UI |

### 1.2 目标受众分层（决定邀谁、拍什么）

| 层级 | 人群 | 痛点 | 推广钩子 |
|------|------|------|----------|
| **P0 核心** | 短剧编导 / 个人创作者 / 小说改短剧 | 分镜慢、定装飘、出片碎 | 「一集竖屏从小说到成片」 |
| **P1 放大** | AI 绘画 / Comfy / 视频模型博主 | 缺「整条业务」内容 | 「你的出图能力接到短剧流水线」 |
| **P2 转化** | 中小 MCN / 工作室工作室工作室工作室 / 工作室工作室 | 人效、合规、统一画风 | 「项目画风锁定 + 合规拦截」 |
| **P3 种草** | 想做副业的小白 | 怕技术、怕翻墙、怕贵 | 「小白教程 · 从 0 到导出」 |

### 1.3 竞品话术边界（弹幕级风控）

预埋一句即可，勿开战：

- vs 纯 Chat 写剧本：我们**一直做到出片**  
- vs 纯即梦/可灵网页：我们是**项目制产线 + 角色一致性 + 分集管理**  
- vs 海外 Agent：我们**中文工作流 + 合规词库导向国内可播**  
- vs 手搓 Comfy：我们把工作流**收成按钮与流水线**，专家仍可接本地节点  

成本/算力敏感（对标秋芝「token 告辞」）：  
**提前说清** —— 出图/出视频吃算力；演示标注「本机 4060 / 云 API / 单任务队列」等真实配置，避免「全自动不要钱」幻觉。

## 二、内容矩阵：一条旗舰片 + 系列弹药

### 2.1 旗舰片（必做，对标秋芝 13 分钟主片）

| 项 | 建议 |
|----|------|
| **标题** | 从零开始，用 AI 做出一条竖屏短剧！【西瓜短剧 Agent 小白教程】 |
| **备选** | 小说进、成片出！桌面 AI 短剧产线 8 步跑通【小白】 |
| **时长** | 12–15 分钟 |
| **承诺** | 看完能自己：建项目 → 选画风 → 出一集分镜图 → 导出至少 1 段成片 |
| **主场景** | 固定一个故事（建议都市甜宠/逆袭，受众广、合规压力小） |
| **素材** | 自制 800–1500 字「可播」短剧本或小说切片（无红线内容） |

#### 八大能力台阶（= 秋芝「8 大用法」）

> 原则：**权限/完成度逐步增强**，每层多一个「上一层做不到的事」。

| 台阶 | 能力 | 画面主演示 | 6 拍里的「结果特写」 |
|------|------|------------|----------------------|
| 1 | 建项与画风锁定 | 新建短剧 + 项目画风 + 9:16 | 风格圣经/画风名出现 |
| 2 | 剧本/事件进产线 | 粘贴或生成剧本、事件改编 | 分集列表 + 有剧本勾选 |
| 3 | 抽资产 | 角色/场景/道具提取 | 角色卡列表 |
| 4 | 定装出图 | 角色图、场景图（跟随项目画风） | **定装图墙** |
| 5 | 分镜拆解 | Agent 拆 3–5 秒镜头表 | 分镜卡片/画布 |
| 6 | 分镜出图 + 审查 | 多参考出图、审核提示 | 分镜图序列 |
| 7 | 图生视频成片 | MiniMax H3 i2v 等 → 时间线 | **竖屏成片播放** |
| 8 | 合规与工程化 | 红黄线提示 / 流水线下一步 / 算力节点一句 | 合规提示或导出 MP4 |

**口播递进绳（必用）：**

- 「只会写剧本不够 → 要锁画风，角色才不崩」  
- 「有定装还不够 → 要拆成 3–5 秒能出的镜头」  
- 「有分镜图还不够 → 要进时间线变成能滑的短剧」  
- 「能出片还不够 → 要过合规，才能安心做内容生意」

#### 旗舰片时间轴（可直接当分镜表）

| 时间 | 镜头 | 内容 |
|------|------|------|
| 0:00–0:15 | 黑底大字 + 成片 3 秒预告 | 「AI 短剧产线」「小说→MP4」；先甩结果 |
| 0:15–0:50 | 全屏人像 | 痛点：分镜累、角色崩、工具散；承诺 8 步跑通 |
| 0:50–1:40 | 录屏+PiP | 启动软件、登录/工作台认路、流水线条 |
| 1:40–3:00 | 录屏 | 建项目、选画风/类型/节奏、9:16 |
| 3:00–4:30 | 录屏 | 剧本进入、事件/分集（点到为止） |
| 4:30–6:00 | 录屏 | 抽角色场景、出定装图；**黄标「跟随项目画风」** |
| 6:00–8:00 | 录屏 | 分镜拆解、镜头表、出分镜图；可加速生成 |
| 8:00–10:00 | 录屏 | 出视频、进时间线、播放成片；**结果墙** |
| 10:00–11:30 | 录屏+人像 | 合规提示、算力/队列一句、失败重试怎么点 |
| 11:30–13:00 | 人像+地图卡 | 八步能力地图；习惯建议；三连+合集+获取方式 |
| 片头片尾 | ≤2s | 西瓜 Logo + 品牌色 |

#### 开场 15 秒口播稿（可直接用）

```
如果你也想做竖屏短剧，但卡在分镜、定装和出片——
很多人还在「这个软件出图、那个软件写剧本、最后靠手工拼接」。
这期用西瓜短剧 Agent，带你从 0 跑通 8 步：小说进、成片出。
小白向，跟做就行。
```

#### 结尾口播稿

```
把今天的能力从弱到强排一下：
画风锁定 → 剧本进线 → 抽资产 → 定装 → 分镜 → 出图审查 → 成片 → 合规与工程化。
建议你先用一个小故事跑通「定装+3 个镜头成片」，再上长篇。
有用就三连收藏，合集里还有画风包和分镜专项。
获取与配置看评论置顶。
```

## 三、讲解与画面规范（西瓜定制版秋芝 SOPs）

### 3.1 镜头配比

| 类型 | 占比 | 西瓜注意点 |
|------|------|------------|
| 全屏人像 | 20–30% | 背景可用深色桌面/品牌角；避免杂乱 |
| 录屏 + 圆 PiP | 55–70% | **深色 UI 反差**：鼠标加大、点击高亮 |
| 章节卡/对比/结果墙 | 10–15% | 黑底大字：「定装」「分镜」「成片」；结果墙用多张分镜+成片 |

### 3.2 信息设计（统一视觉语法）

| 语法 | 用法 |
|------|------|
| 黄底高亮 | 只盖「跟随项目画风」「3–5 秒一镜」「红线拦截」等胜负手 |
| 黄标签 | 贴在流水线步骤：画风/剧本/角色/场景/分镜/成片 |
| 橙虚线框 | 圈「下一步」按钮、导出、审查通过 |
| 左右分屏 | 无画风 vs 有画风；手写分镜 vs Agent 拆镜 |
| 结果墙 | 定装 4 宫格 + 分镜条 + 成片帧 |
| 能力地图 | 片尾 8 步一图（方便截图收藏） |

### 3.3 字幕与声音

- 全程硬字幕，底中，避让左下 PiP  
- 专有名词可保留：Agent、MP4、9:16、ComfyUI（首次口播解释）  
- AI 生成等待：**必须加速或口播「它在拆镜/出图」**，禁止干等转圈  
- BGM：轻科技，人声为主；成片展示段可略抬 BGM  

### 3.4 演示环境清单（拍前一天）

- [ ] 演示专用项目：「都市·告白逆转」等无敏感内容  
- [ ] 画风已种子同步，角色/场景图预跑一批「保底素材」（现场只重跑 1–2 张真操作）  
- [ ] 分镜 6–10 镜可控时长；成片预生成 1 条备用，现场再跑 1 段增强真实感  
- [ ] 合规演示用**虚构温和黄线例**，不出现真实敏感词  
- [ ] 通知关闭、分辨率 1080p/1440p、缩放 100–125%  
- [ ] 账号/卡密/机器码等隐私打码  
- [ ] 版本号口播或角标：`v0.x.x`（与 `使用说明` 一致）
